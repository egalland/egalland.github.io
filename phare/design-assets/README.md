# Décors sources du port d’Innsmouth

Les deux illustrations originales en PNG ont été générées pour *Innsmouth — Le port oublié*. La composition horizontale de 1536 × 1024 pixels et la composition portrait de 941 × 1672 pixels sont les sources des versions WebP servies dans `../assets/`.

Les fichiers de la police Pirata One se trouvent dans `../vendor/`, avec sa licence OFL. `python scripts/convert-font.py`, exécuté avec FontTools installé depuis le dossier `phare`, reconstruit les contours utilisés par Three.js pour les lettres du port.
