# Project data

Permanent IDs use PRJ-001 and increment. Slugs may change; IDs must not. The initial catalogue contains three demonstration projects. Estimates are labeled, measured statistics remain null until recorded.

The D1 schema lives in db/schema.ts. The portable per-project manifest contract is documented in WORK_SYNC.md. GitHub metrics are reserved in the schema; this first release does not claim automatic GitHub synchronization.
