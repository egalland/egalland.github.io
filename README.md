# Configurateur de cuisine

Dessiner les murs, placer les équipements et calculer les matériaux pour une pièce. Le plan de départ est un exemple rectangulaire de 4,20 × 3,60 m.

## Démarrage

Utiliser Node.js 22.13 ou supérieur. Installer les dépendances avec `npm ci`, puis lancer `npm run dev`. Pour vérifier la construction de production et le rendu HTML, lancer `npm test`. Les scripts de construction utilisent Bash et GNU timeout.

Le manifeste local définit uniquement les liaisons de stockage nécessaires au développement.
