# Orbite

Station de développement avec carte interactive des projets et activité GitHub publique. Cette édition démarre avec un inventaire vide.

Construire avec `node scripts/build.mjs`. Le point d’entrée du Worker est `dist/server/index.js`. En local, utiliser un serveur compatible avec le format Cloudflare Workers ES modules. L’API de démonstration est en lecture seule. Les données de démonstration se configurent dans `web/seed.json`.
