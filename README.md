## Créer des dépôts GitHub dédiés

Le fichier `editions.json` contient les empreintes vérifiées des éditions qui peuvent être extraites dans un dépôt indépendant. Avec Git, Python 3 et GitHub CLI, afficher la liste depuis une copie de cette branche.

```sh
python3 scripts/creer-depots.py
```

Pour créer un dépôt précis avec le compte `egalland` connecté à GitHub CLI, passer son nom à la commande.

```sh
python3 scripts/creer-depots.py --publier filament-atelier
```

L’option `--publier` sans nom traite toute la liste. Le script vérifie chaque arbre Git avant la création et après l’envoi. Il crée un premier commit à partir des fichiers de l’édition choisie. Les dépôts privés et les dépôts déjà peuplés sont ignorés. Les historiques restent accessibles dans leurs branches d’origine.
