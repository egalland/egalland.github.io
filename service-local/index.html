Comment vérifier avec un collègue ?
  1. Une seule personne extrait le pack dans un dossier réseau partagé.
  2. Chaque personne lance le même fichier LANCER.bat depuis ce dossier réseau. Chacun obtient sa propre adresse locale ; elle n’est pas à envoyer aux collègues.
  3. Ajoute un message dans Jira, suivi ou Simulations. Le collègue doit le voir dans le même onglet après quelques secondes.

Garde la fenêtre du lanceur ouverte pendant l’utilisation. Fermer seulement cette page laisse le service actif ; ferme le lanceur ou fais Ctrl+C pour l’arrêter. Les messages restent dans le dossier partagé.

Vérifie que le chemin affiché en haut désigne bien le partage commun. Si chacun utilise une copie locale du pack avec la configuration par défaut, les données seront séparées.

Ce test utilise les droits Windows sur le dossier. Le nom ou identifiant affiché signe le message ; ce n’est pas une authentification. Le service écoute uniquement sur ton PC et ne nécessite aucun port entrant pour les collègues.

Pour ce premier test, seuls l’ajout et la lecture sont proposés. Chaque ajout crée son propre fichier : aucune fiche existante n’est modifiée. Ce n’est pas un moteur SQL.
