Mode d’emploi et limites du test
  1. Copie ce HTML dans ton dossier réseau, ou garde-le sur ton PC. Ouvre-le directement avec Edge ou Chrome.
  2. Clique sur Choisir le dossier réseau, sélectionne le dossier parent de la base et accepte l’accès en lecture / écriture. Si nécessaire, passe par le lecteur réseau visible dans l’Explorateur Windows.
  3. Renseigne ton identifiant, puis ajoute une fiche. Les trois tables sont jira, suivi et simulations.
  4. Sur un autre PC, ouvre le même HTML et sélectionne exactement le même dossier parent. La fiche doit apparaître au prochain rafraîchissement.

Chaque poste doit autoriser l’accès au dossier. Le navigateur peut redemander cette autorisation à la réouverture. Les droits du dossier réseau continuent de s’appliquer.

Il s’agit d’un accès direct à des fichiers partagés : cette page ne lance pas de serveur HTTP ou SQL. Aucun poste n’a besoin de garder la page ouverte pour que les fichiers restent enregistrés.

Prototype : évite que deux personnes modifient la même fiche au même moment. Une vérification détecte certains conflits, mais il n’y a pas de verrou distribué ni de transaction SQL. Le identifiant sert à signer les fiches ; ce n’est pas une authentification.

Si le navigateur ou la politique informatique bloque l’accès au dossier, la page affichera l’erreur. Un raccourci SharePoint non synchronisé n’est pas un dossier réseau directement accessible. Le rafraîchissement fonctionne tant que la page est ouverte ; les onglets en arrière-plan peuvent être ralentis.

Référence technique : File System Access API — documentation Chrome.

3Mini-console SQL · lecture seule

Les requêtes lisent les fichiers du dossier. Les ajouts, modifications et suppressions se font dans le formulaire.

Aucune requête exécutée.

Syntaxe disponible et fichiers créés 
SELECT * FROM jira;
SELECT titre, statut, identifiant FROM simulations WHERE statut = 'En cours';
SELECT COUNT(*) FROM suivi;
SELECT * FROM jira WHERE titre LIKE '%fournisseur%' ORDER BY modifie_le DESC LIMIT 20;

Une seule condition WHERE : =, != ou LIKE. Pas de jointure, de AND, de OR ou de requête d’écriture. Les mots-clés et noms de colonnes ne tiennent pas compte de la casse ; les valeurs comparées avec = sont exactes. LIKE ignore la casse. Pour une apostrophe dans une valeur : 'L''exemple'.

Colonnes : id, titre, statut, identifiant, notes, cree_le, modifie_le, revision.

Les données métier sont enregistrées uniquement dans ces fichiers. Seuls ton identifiant et, si possible, l’autorisation du dernier dossier sont mémorisés dans le navigateur. Ce prototype ne lit pas les fichiers l’application de réunion existants.
